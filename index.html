How to get Zoom's audio into this
  1. Simplest: play the Zoom call through your speakers and let this page listen through your microphone. Works immediately, no setup, but picks up room noise too.
  2. Cleaner (recommended for real use): install a free virtual audio device — VB-CABLE on Windows, or BlackHole on Mac. Set Zoom's speaker output to the virtual cable, then in your browser's microphone permission prompt, select that virtual cable as the input. This feeds Zoom's actual audio straight into the transcriber with no room noise.
  3. Click Start listening below and allow microphone access when your browser asks.
  4. Language: "Hindi + English (mixed)" is the default — it writes Hindi speech in Devanagari and English words/sentences in Latin script within the same transcript, which handles normal Hinglish code-switching well. If the call is purely in one language, switching to "English (India)" or "English (US)" can improve accuracy for that language alone. You can change this while listening; it briefly restarts recognition without losing what's already been transcribed.
  5. Listening on the same phone that's playing audio through a Bluetooth speaker: this works out of the box — the app listens through the phone's own microphone, so anything audible in the room (YouTube, Zoom, a Bluetooth speaker) gets picked up and transcribed, regardless of source. A few things to know:
    • Use Chrome on Android. iOS Safari doesn't support this speech recognition feature at all, on any browser.
    • Keep this browser tab open and in the foreground — phones suspend background tabs, which stops listening. The screen will now stay awake automatically while you're listening.
    • Some Bluetooth speakers have a built-in mic and can make Android route both playback and mic input through the Bluetooth device once this app requests microphone access — this can quietly drop the audio to low-quality mono. If transcription accuracy seems off or playback sounds worse after starting, disconnect the speaker's mic capability (or use a Bluetooth speaker with no mic) so the phone's own mic stays in use.
    • Place the phone close enough to the speaker that its mic can clearly hear it over any room noise.
This uses Chrome/Edge's built-in speech recognition, so it only works in Chromium-based browsers, and needs an internet connection (the recognition itself runs on Google's servers, but no data is stored by this app — closing the tab clears everything).
